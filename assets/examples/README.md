# Examples

Finished projects made with this skill. Open `index.html` in a browser to preview
(space = pause, ←/→ = step a frame); render with the project tools after `new_project.py`.

| Folder | What | Formats |
|---|---|---|
| `showreel/` | 15 s motion-design showreel from the one-line prompt "做一段 15 秒动态图形视频，展示你是多么出色的动态设计师，像简历的展示卷。全力以赴。" | 9:16, 16:9 (`?fmt=16x9`) |
| `coffee-hype/` | 20 s opening-promo ad for a café | 9:16 |

「山野咖啡」 in `coffee-hype/` is a **fictional brand** made up for testing; the address and offer are
placeholders, not a real shop or promotion.

The example `index.html` files carry the engine version they were built with. Start new work from
`scripts/new_project.py`, which copies the current engine.
